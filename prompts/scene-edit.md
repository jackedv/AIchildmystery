# 绘本结果画面
第一张图是唯一原始场景，其他图仅是已经存在物体的造型参考，不是新道具。保持第一张图的横屏宽高比、镜头、两岸、河流、森林、粉色天空、手绘纹理和儿童绘本风格。画面里原本只有一个公主，避免重复角色。
优先借用所提供的本地物体参考，严格保持公主的脸、金发、王冠、白裙与蓝色饰带；保持木桶的橡木纹理、金属箍、开口和两只的数量；保持桥板和滑轮的造型。改变位置或旋转可以改变可见角度，但不能换成另一种木桶、另一个公主或新样式的木架。按参考图片对应关系辨认每张图，不把同一物体的参考图当成额外数量。

根据“已确认的方案和结果”编辑第一张图，仅改变方案涉及的物体及必要的因果影响。保持未参与物体的外观和原位置。两个木桶原本在左岸，长桥板原本在左岸铰接处竖立，木架滑轮在右岸。不要恢复到旧版木桶在右岸或短桥板的布局。参考物体不能额外复制进场景。

这是行动全部完成后的最终定格，不是过河过程。成功时公主已经离开桥、绳子或木筏，双脚站在右岸的草地上；她不是还在左岸、桥中央或水面上。公主保持原图的体型比例和画面内高度，不放大成巨人。右岸为画面右侧木架旁的绿色陆地，公主可站在右岸前景，避免遮住金属滑轮顶部。保留她使用过的支撑、漂浮或牵引结构来说明因果，但人物必须已经到岸。

仅当方案是放下桥板搭桥时：保持原本单块旧木板的材质与大致尺寸，铰接端留在原左岸铰接位置，另一端搭在对岸；不要扩成宽阔新桥、拼出多块木板、移动铰接点或缩窄河流。若确认的方案把木板移作其他用途，则按该用途移动原来的唯一一块板，不保留左岸竖板、不凭空增加一根桨。没有参与的木桶、木架、绳子和石块不移动。

移动不是复制：每件已搬走的物体必须从原位置移除。原图只有两个木桶、一块旧桥板、一个公主；桶的前后重叠也不能变成第三只桶。已解下使用的吊绳不能仍完整挂在树上。只画最终留在场景中的结构与材料，不重复画行动过程。成功人物已经上岸，不需要仍坐在浮具或握住绳子；用过的浮具可以停靠右岸水边。
移动到右岸的长桥板仍然是原来的长板，画面中的长度应与原图大致相当，并完整可见；可以平放或斜靠在岸边，不能缩成短桨、木片，不能靠遮挡大部分长度掩盖尺寸变化。原金属件也应延续。

失败时表现更可能的物理结果，公主仍处于安全位置，不夸张变成灾难。任何失败不得描绘受伤、沉入水中或死亡。
