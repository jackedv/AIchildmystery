# 绘制方案的关键过程
图1是本关无公主背景，后续图片是公主与原有物品的本地参考。保持原镜头、横屏比例、粉色天空、森林绘本质感及无关物体的位置。优先借用本地素材的形状、颜色、材质和数量，不把参考图当作新增道具。

只画 processFrame.keyMoment 指定的一幅关键动作画面：让孩子一眼看懂“公主怎么做”，而不是只看到“公主已到终点”。planOutcome 是完整方案是否可行，不是这一帧必须已经完成目标。成功方案也可以画在河中央、城门外或通道中。

公主必须亲自参与动作。以 princess-success.png 为角色身份参考，保持同一张脸、金色长发、皇冠、白裙和蓝蝴蝶结，允许调整姿势、朝向、手臂和手持物；不是把静止原图粘在背景里。公主提篮时手与篮柄接触，出示单据时让盖章纸张可见；搭木筏时公主坐在或站在绑好的浮具上；荡绳时手抓绳，身体处于摆荡中。只绘制一个公主。衣着可随玩家明确的装扮动作调整，但不能凭空添加新制服、武器或工具；“装作送货人”可以是原裙装提菜篮出示原有送货单，不需要新衣服。

动作与参与物体要清晰可读。根据 keyMoment.princessLocation 摆放公主；不要另画一个终点公主，不将正在行动改为抵达后静止站立。尽量使用接近初始人物的可辨认尺寸，随合理透视改变，不故意缩成远处难以看清的小人。守卫、车夫与无关物品保留；不增加人。

移动不是复制：被提起的篮子从原地移除，被解下的绳子从树上移除，被移动的桶从岸边移除。只调整参与方案的物品，保留大致尺寸与本地造型，允许轻微手绘差异和绘本夸张，不将长板变成短桨、空桶变成陌生船。

不重新判断方案，不制造新危险，不画受伤、溺水、惊吓或死亡。失败方案可以画安全尝试中最能说明问题的瞬间，但不能画成成功抵达。不画魔法飞行或不存在的怪兽。无 UI、按钮、木牌、输入框、额外文字标签和解释。输出一张完整 PNG 场景，包含正在执行动作的公主。

数量必须遵守 facts.objectCounts。第一关全图总共只能有两个桶，两个桶各一个完整桶口、一个桶身；并排绑紧，不画第二排桶或背后多出来的桶口。第二关只有一名守卫、一个菜篮、一辆送货车、一架梯子。
