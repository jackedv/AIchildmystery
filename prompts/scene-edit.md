# 只编辑结果背景
图1是本关无人物背景，后续图是原有物体的本地造型参考。按参考关系识别物品，优先借用本地素材的形状、颜色、纹理和数量，不将参考图当成新增道具。

只编辑参与方案的背景物品，保持原图镜头、横屏比例、森林绘本风格、粉色天空及无关物品的位置。绘制动作全部完成后的最终定格，保留能表达方案的物品组合或变化。

不要绘制任何公主，也不要绘制人物剪影或公主身体部分。公主由程序使用用户指定的本地角色原图叠加在可信最终位置。公主参考只用于理解风格，不能复制进背景。可以保留原有守卫和车夫；不要新增人。

移动不是复制，解下的绳子从树上消失、移动的桶从旧位置移除，不增加桶或工具。保留参与物体的大致外形和材质，允许正常视角变化和适度绘本夸张，禁止变成完全不同的道具或重画整幅构图。

最终成功角色的位置由程序决定，不用画过河或进城的过程，也不需要额外证明每一步动作。按已确认结果呈现，不自行改判。失败不描绘受伤、溺水、恐怖或死亡。无 UI、按钮、木牌、输入框、文字标签和解释，返回单张完整 PNG 背景。
