# 本地绘本解谜游戏技术方案

更新日期：2026-10-11。以用户已批准的实施计划及最新判定、评分要求为准。第一期只做入口、选关和第一关。

## 运行方式

网页使用 HTML、CSS、原生 JavaScript，负责绘本界面、真实输入控件、场景热点、音乐和进度。Node.js 是运行在用户电脑上的小服务：提供网页，读取本地提示词和密钥，转发火山方舟请求。它监听 `127.0.0.1:4173`，无需部署。

没有游戏引擎或框架依赖。当前玩法以静态场景观察、文字描述和 AI 画面编辑为主，不需要逐帧碰撞模拟；固定 1672×941 画布整体等比例缩放，保证人物和热点相对位置一致。不以精确物理数值引擎代替开放方案理解。

双击启动器调用 `tools/start-local.ps1`：准备项目内 `.tools/node.exe` → 准备空 `.env` → 检查本机服务 → 隐藏启动进程 → 等待服务就绪 → 打开浏览器。重复启动不会叠加已有服务。停止脚本核对已记录进程的执行路径和本项目服务路径，再结束进程。

准备脚本只从官方 Node.js 下载 24.19.0 Windows x64 ZIP，核对官方 SHA-256，解压于 `.tools`，没有全局安装。当前机器已准备项目内运行环境；Git 不上传它、密钥、日志和测试截图。

## 接口约定

`GET /api/health` 返回应用名、版本 2 和 `configured` 布尔值，不返回 Key。

`POST /api/attempt` 的 JSON 只接受固定第一关编号 `princess-river-1`、3–80 字 `text` 和最多五条 `{text, question}` 追问上下文。网页不能指定模型、提示词、物体属性、成功状态或任意本地文件路径。单次请求体上限 12 KB；中文按完整 UTF-8 字节流解码。

服务返回以下状态：

| 状态 | 内容与行为 |
| --- | --- |
| success | 结果图片、三部分解释、五项有效评分；核图后才保存通关 |
| failure | 结果图片和具体常识原因；无通关评分 |
| clarify | 一个必要问题，保留原句及原场景 |
| unavailable | 空密钥，提示 AI 尚未接入，未调用外部服务 |
| system_error | 配置、限额、超时、格式或图像异常；不算玩家失败 |

服务同一时间只处理一个方案，多出的请求为 409。后端 165 秒取消，前端 180 秒兜底；切页或关闭请求会取消上游等待。模型调用不能保证平台立即停止已经计费的生成工作。

## AI 调用与结果判定

平台基础地址固定为 `https://ark.cn-beijing.volces.com/api/v3`。文字模型默认 `doubao-seed-2-1-pro-260915`，生图默认 `doubao-seedream-5-0-flash-260915`，可在本地 `.env` 更换同平台支持的模型标识。

1. **理解与判定。**把理解、常识判断两份 Markdown 放入系统消息；关卡事实、图片、玩家原句和追问记录放入待分析消息。玩家输入中的“忽略规则”等内容不能成为系统指令。文字调用使用图片理解、结构化 JSON 和关闭额外思考的参数。
2. **顺序校验。**结构包含 clarity → constraints → physics → goal 四步；第一次不通过后，后续必须标记未评估。四步通过才可成功。需要追问不生图；最多连续五次，再要求完整重述。低置信度也返回追问。
3. **成功评分。**同一次文字判定返回五个唯一维度，每项 0–10 整数和短理由。评分依据这次方案，不反推通关；失败和追问评分数组为空。缺项、越界、重复或顺序矛盾按模型格式错误处理。
4. **编辑画面。**原图第一张，公主参考常驻，其余按方案涉及的物体从关卡本地参考映射中选取。最多十张，先覆盖每类涉及物体，再补充石块的其他外形；滑轮与长绳共用的文件去重。树叶、土等没有拆分素材时以原图为准。每张图在提示词中说明用途，参考图不增加物体数量、不决定摆放位置。只编辑已确定的变化，不传按钮和文字素材。单张 PNG、Base64 返回、原场景比例，不使用该型号不支持的连续生图参数。
5. **核对与解释。**文字模型看原图、本地外观参考和最后一张生成图；检查主角、数量、样式、关键结构、背景与判断是否矛盾，生成理解/变化/原因三部分儿童语言。核对失败为图像异常，不能改物理判定。图像解码成功后浏览器才显示、保存完成记录和评分。

无需精确密度、长度或拉力阈值，也没有预设成功名单。生成阶段固定的条件可以减少外观偏差，无法数学保证图像保真，真实效果须联网测试。

## 私有数据与服务边界

Key 只在 `.env` 或当前进程的 `ARK_API_KEY` 环境变量中；前端不持有，日志不输出。白名单仅提供 index、样式、src JS 和 assets，禁止读取 `.env`、提示词、server、`.git`、`.local`。Host 必须是本机，跨站 Origin 拒绝。

浏览器仅保存版本 2 进度、音乐开关与最多 50 条尝试摘要。旧版演示记录仅迁移为历史，旧版密钥存储删除，不把旧演示认定为 AI 通关。密钥之外，玩家提交文本会在本机 `.local/attempts.jsonl` 留存；不默认上传 Git。
