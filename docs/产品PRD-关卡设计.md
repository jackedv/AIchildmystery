# 当前产品与关卡约定

2026-10-11。原始核心稿保留为「游戏设计.md」，当前实现以用户后续明确调整为准，取消旧稿精确物理阈值。

## 流程和范围
面向 7–10 岁儿童，桌面横屏 1672×941 优先。故事封面 → 两页关卡本 → 本关两段黑底剧情 → 场景观察/一句话方案 → 结果 → 重玩/下一关/返回。完成第一关解锁第二关，真实旧版第一关完成记录保留，旧演示不算通关。
第一关「过河不拆桥」用最新版河岸素材（桶在左岸、长板、绳到河中）；第二关「悄悄进城」用素材目录「第四关」的含梯子完整背景，游戏排序为第二关。人物按用户提供的两图固定：初始/重玩挑战图、成功站立图。第一关旧人物只在副本中去除，避免重复叠加。
第一关 UI 原文：过河不拆桥；想想办法，帮公主安全过河吧！；请输入你的想法...。第二关沿用木牌与同样控件风格。木牌下拉后停留 2 秒，上拉后保留关卡约定按钮。开站加载图使用原素材、进度线性至少 2 秒；AI 等待留在本关，只有中央圈。

## 观察与表达
热点悬停约 300ms、点击或键盘可看名称/位置/特性，不提示操作和组合答案。输入建议 3–80 字，允许逗号连接的计划，不按标点机械否决。真实单行控件，中文输入法选字不误提交；等待不能重复发送，返回取消，迟到结果不能覆盖新关卡。

## 判定尺度
固定顺序：表达清晰 → 本关限制 → 基本常识 → 本关目标 → 最终状态。采用儿童绘本的宽松常识，允许适度夸张、日常操作省略和巧妙组合，主要因果合理即可。默认公主乘坐自己制作的浮具，补足上筏、扶稳、绑紧、撑岸/手划水、普通走动等动作，不索取位置、推力、防滑、精确尺寸或工程证明；潜在风险不等于必然失败。
只有真的不清楚对象或主要动作才一次追问一个必要问题，最多五次，不重复审问细节。不用成功名单或关键词匹配。不能凭空变出工具、飞行、瞬移、怪兽援助或跳过大海；薄叶单独承载人仍明确不成立。没有 Key 不模拟结果，系统问题不计为失败。

## 两关的可信事实
第一关目标为公主到右岸，不能独自游过河。仅现有物品：桥板、可解的吊绳、滑轮长绳、双桶、石块、河流、树叶、岸土等。空桶能浮，两个绑成浮具较稳，可以坐/站进桶，无须额外板面；填放岸土、摆石支撑等日常整理可以按绘本尺度补足。
第二关目标为进入城墙内侧庭院，禁止伤人、报警和图外物品。守卫验单；告示允许有效送货单持有者随货进入；货篮旁有有效盖章送货单；不透明篷布车验单后正常进城。完整木梯、宽平墙顶、庭院草地、外侧可打开插销的未锁侧门、干燥且两端可见的通道均为可信事实。不能猜隐藏锁、通道太窄或守卫必然发现。任何组合都按这些事实判断，用户举例不实现成固定答案表。

## 画面、反馈与评分
先判断，再以本关背景和必要本地物体参考编辑无公主结果背景；随后本地合成固定公主，核对最后完整画面并用儿童语言解释因果。成功终态为右岸/庭院内；不要求画完整过程。明显角色重复、新道具、主要布局错误或终态矛盾时最多重生成一次，仍异常返回系统错误，不改判孩子。
成功给物理推理、想象力、观察力、规划力、安全意识五个 0–10 分及短理由。评分针对本次方案，不评价孩子能力，无总分或排名；没写专业安全措施可影响分数，不能倒推否定成功。其他状态不显示通关分数。
成功/失败完整弹窗显示 2 秒，整块缩小到左上结果圆钮，点击完整重开并保持；操作时停倒计时，Escape/圆钮可收起，换关/重玩清理。成功按钮依次为再试一种方法、进入下一关、返回关卡本。第二关后提示后续待开放。追问与系统错误保持提示。

## 进度与音乐
各关完成状态分别记忆，重玩恢复本关初始场景。首次交互开始背景音乐，一个循环音轨，记忆开关，剧情降低音量，窗口隐藏暂停。进度只在当前浏览器保留。
