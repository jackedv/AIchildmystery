# 第一期开发表达与关卡约定

2026-10-11。原始核心设计稿为同目录「游戏设计.md」；该稿部分飞书表格未导出。本文件记录用户在实施计划及后续消息中明确调整的内容，当前实现以这些新要求为准。

## 范围和主流程

面向 7–10 岁儿童；电脑横屏优先，基准 1672×941。故事书封面 → 关卡本 → 两段黑底剧情 → 第一关 → 结果反馈 → 重玩/返回。仅第一关可进入，其余为待开放。

第一关「过河不拆桥」目标是公主安全到右岸。以最新「关卡背景.jpg」完整原图为初始状态，木桶在左岸；不重复叠加人物或物体。旧版拆分文件的坐标说明失效，热点重新按新图配置。

界面保持三句原文：过河不拆桥；想想办法，帮公主安全过河吧！；请输入你的想法...。返回、音乐、木牌、输入框按原 UI 参考的位置和比例，背景使用新版关卡图。

## 观察、输入与状态

物体约 300 ms 停留后显示事实，也可点击或键盘查看，不直接暗示解法。可用图中人物、木板、绳子、滑轮、木桶、石块、河水、大树、树叶、岸土、草花果实，不凭空增加工具或能力。

限定：只能使用图中出现的物体；用一句话描述。单行输入建议 3–80 字，逗号串联步骤可以算一句，独立多句应要求重述。等待时禁止重复发送，切页可取消；追问保留原句、原场景，每次只问一个必要问题，最多五次。未接入不演示成功，系统故障不算失败。

## 5.5 结果判定（用户最新要求）

顺序固定：

1. 输入是否清晰。
2. 是否违反关卡限定条件。
3. 是否满足物理常识。
4. 是否达成玩家目标。
5. 输出最终状态。成功通过后显示五维 0–10 分五边形和每项短解释。

| 维度 | 本次方案的评分依据 |
| --- | --- |
| 物理推理 | 是否正确利用物体特性，有合理因果，如漂浮、压重 |
| 想象力 | 是否突破常见用途，形成新用途或组合；失败也可有创意 |
| 观察力 | 是否利用位置、形状、材质及环境的关键细节 |
| 规划力 | 是否合理安排先后步骤，避免遗漏与矛盾 |
| 安全意识 | 是否识别滑倒、倾翻、支撑不稳并保护角色 |

五项不是通关硬门槛，不给总分或排名，不评价孩子能力。常见成功办法不自动满分。失败可肯定创意，不因此推翻常识，也不显示通关评分。挖土铺河、绳锯树枝等举例需要逐步检查可行性，不预设成功。

## 常识与结果画面

取消旧版公斤、厘米、承重阈值，只评估基本因果、稳定性、浮力和安全到岸。叶子浮在水上不等于能承载公主。允许补足普通操作，不能替玩家增加决定成败的工具或关键步骤。

先作常识判定，再编辑结果画面，最后核图并解释。生图借用本关拆分素材固定外观；原图决定构图和数量。无关元素保留，不画 UI、伤害或恐怖。明显矛盾为生成异常，原场景和句子保留。

## 持久化与声音

通关后显示已完成，下一关为已解锁·待开放；重玩恢复原始关卡。声音首次点击开始后播放，一次只有一个音轨，页面切换不重复启动；可关闭并记忆，剧情降低音量，窗口隐藏暂停。当前进度只在同一个浏览器内保存。
