# 美术素材使用记录

游戏背景与物体来自用户项目内「设计素材」，角色采用用户另附的两张 PNG 原图。保留全部原始来源。第一关仅在副本中移除旧公主，第二关采用含梯子的完整背景；初始角色由本地挑战原图合成；关键过程以站立公主为身份参考，由模型调整动作，不再叠加静止终点人物。

## 输入条去字

输入条原素材包含画入的「请输入你的想法...」，实际网页需要可输入的文字控件，因此创建去字副本 `assets/ui/input-clean.png`。使用会话内置 imagegen 编辑能力，仅处理占位文字，保留透明背景、奶油黄输入条及右侧纸飞机图标。原素材未覆盖。

最终编辑要求：移除输入条内部已经画入的中文占位文字，只填补文字所在区域的原有底色和纹理；保持输入条形状、尺寸比例、金色描边、纸飞机提交按钮与透明区域；不添加文字、背景、控件或其他物体。

这是生成式去字副本，纸飞机与纹理可能存在轻微差异；已在实际渲染中确认输入不出现两层字。标题、返回、音乐使用提供素材，CSS 抵消源图片透明边距，场景目标文字为真正网页文字。

本地参考图使用 girl、barrels_pair、bridge_plank_tall、pulley_rig_with_rope、rope_tree 和四张 rock。原始素材导出的旧 manifest 引用旧名字/位置，未用于本次初始化或热点。

## loading 页面
直接复制用户新增的 `loading_background.png`、`progress_bar_empty.png` 和 `progress_bar_full.png` 到 `assets/loading/`，原文件未改动。背景自带「小小公主」标题；动态数字与进度条由网页叠加，不采用烘焙 54% 的预览图。
按该组素材提供的位置、尺寸与透明边距配置；绿条和空条采用互补裁切，避免重叠轮廓，不横向压缩整条图片。字体采用素材说明建议的 28px 粗体及 #805839，原字体文件未提供，中文字形有系统字体差异。

## 两关固定角色与第二关木牌
角色原图保存为 assets/characters/princess-challenge.png（初始）与 princess-success.png（过程身份参考）。Sharp 只在初始场景保持原始宽高比和透明背景叠加挑战人物；过程交给模型根据同一公主参考绘制动作，不再按终点位置贴静止人物。
第一关使用内置 imagegen 编辑无人物副本，最终仅把生成图的旧角色轮廓区域合入原图，其他区域使用原始背景像素。保存 assets/level-1/background.png，初始合成保存 scene-initial.png。编辑要求：仅移除原公主及其轮廓，用周围草地/石块自然补足；保持河流、木板、绳子、双桶、树木、天空、镜头和构图；禁止重画其他物品或新增角色。原图未覆盖。
第二关木牌用内置 imagegen 去字生成 assets/ui/title-board-empty.png；要求仅移除字形及其阴影，以木纹填补，保留双层木板、绳子、轮廓、透明背景及森林绘本风格。网页叠加“悄悄进城”，第一关仍保留原始标题美术。
各关初始副本预生成并提交，无需首次联网生图。过程画面联网编辑，角色以本地站立原图为身份参考；保持脸、金发、皇冠、裙装和蓝色蝴蝶结，允许提篮、坐筏等动作。后续物体拆分参考继续按本关映射选择。
