# 美术素材使用记录

所有游戏素材来源于用户项目内「设计素材」，初始场景直接使用新版「关卡背景.jpg」。没有对该背景做拼接或重绘，人物、木桶等拆分素材只作为 AI 外观参考。

## 输入条去字

输入条原素材包含画入的「请输入你的想法...」，实际网页需要可输入的文字控件，因此创建去字副本 `assets/ui/input-clean.png`。使用会话内置 imagegen 编辑能力，仅处理占位文字，保留透明背景、奶油黄输入条及右侧纸飞机图标。原素材未覆盖。

最终编辑要求：移除输入条内部已经画入的中文占位文字，只填补文字所在区域的原有底色和纹理；保持输入条形状、尺寸比例、金色描边、纸飞机提交按钮与透明区域；不添加文字、背景、控件或其他物体。

这是生成式去字副本，纸飞机与纹理可能存在轻微差异；已在实际渲染中确认输入不出现两层字。标题、返回、音乐使用提供素材，CSS 抵消源图片透明边距，场景目标文字为真正网页文字。

本地参考图使用 girl、barrels_pair、bridge_plank_tall、pulley_rig_with_rope、rope_tree 和四张 rock。原始素材导出的旧 manifest 引用旧名字/位置，未用于本次初始化或热点。
