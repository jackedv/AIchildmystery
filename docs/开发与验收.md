## 已验证

17 项自动测试通过：空密钥不联网或通关；指定模型与原图调用；本地参考选择、去重及十图上限；失败、追问、五次上限；非法对象/格式；图像矛盾、在途公主和尺寸错误不能成为通关；认证/限额/坏图；输入限制；判定顺序和五维评分范围；本机静态访问及私有路径隔离；超时、退出取消及重复请求释放；旧演示迁移和完成状态保留。

实际浏览器走通封面、选关、两段剧情、观察、约定、中文输入。早期无 Key 时检查未配置提示；独立端口 4180 假数据仅用于成功评分、失败、追问五次、图片异常、重玩、完成后刷新、退出等待的界面分支。正式入口 4173 没有演示判断逻辑。

配置 Key 后，在正式网页提交模糊句子、详细双桶方案和搭桥方案；实际调用模型后生成右岸终态、解释和五项评分，刷新关卡本显示已完成。统一 AI 等待页可取消返回，退出后重新提交正常处理，不被旧请求覆盖。最终版本的搭桥方案已完整通过包括尺寸保持的核图；重玩恢复原图后提交树叶方案，实际返回失败、左岸画面和无评分反馈。

首次加载采样：约 462ms 为 20%、1116ms 为 52%、1767ms 为 85%、2231ms 为 100%，2451ms 已退出 loading；数字与叶子使用同一线性进度。木牌实测完成下拉后停留约 2 秒，再收至上边缘。

截图保存在被 Git 忽略的 `verification/`，区分正式界面与 fixture 评分画面。检查尺寸为 1672×941、1366×768、1920×1080 和 932×430 横屏；场景按比例缩放，没有裁掉关键物体。竖屏提供旋转提示，非本期主要版式。

## 真实 API 样本与发现

用户已配置本机 Key。文字模型 `doubao-seed-2-1-pro-260915`、图片模型 `doubao-seedream-5-0-flash-260915` 均实际返回 HTTP 200。已验证图片接受原比例尺寸、多图参考、单张 PNG/Base64，文字接受图片理解和结构化输出。密钥、原始响应、诊断图和截图未加入 Git。

| 思路/情形 | 模型样本返回 | 实测范围 |
| --- | --- | --- |
| 把它弄过去 | 中性追问 | 文字接口、正式网页 |
| 放下长木板搭桥、慢慢走过 | 成功、右岸终态、五项评分 | 完整接口和最终版本正式网页 |
| 铺满树叶踩着过河 | 物理常识失败、无评分 | 完整接口 |
| 图外小船 | 违反条件失败、后续不评估 | 完整接口 |
| 搭石头过河 | 追问摆放方式 | 文字阶段，无生图 |
| 抓住吊绳荡到对岸 | 按场景几何判失败 | 文字阶段，无生图 |
| 木板做木筏 | 追问移动方式 | 文字阶段，无生图 |
| 石头砸岸土铺河 | 按土遇水软化、冲散判失败 | 文字阶段，无生图 |
| 木板、双桶、绳子绑筏但没写移动方式 | 追问怎样到对岸 | 文字阶段，无生图 |
| 解绑、并排绑桶、低坐、用木板划水 | 判成功；出现过正确终态，也出现过材料变形 | 完整接口、正式网页 |

上述是有限样本的模型判断，不是预设答案或普遍定论。联调发现并修复：成功画面有时公主仍在途中；有时保留被搬走的木板副本或新增短桨；早期核图遗漏长板缩短。现在检查位置、外观数量、尺寸、背景与因果结构，第一次不符按具体观察重生成一次。最新双桶尺寸异常被正确拦截为系统错误，没有判孩子失败。

关键细节缺失曾被直接判失败，已改为中性追问并复测石路、木筏和未写移动方式的组合。没有为这几种想法设置固定成功名单。

完整调用链已见约 25–65 秒的样本，发生重生成时更长，不是性能保证。生图仍有随机外观偏差，核图也可能误读；样本证明链路可用，不能证明所有开放方案都判断正确。未对账号费用作估算。
