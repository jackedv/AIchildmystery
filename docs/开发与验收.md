# 开发与验收记录

2026-10-11。本版包含故事入口、关卡本、过河第一关、城堡第二关、固定角色素材，以及儿童绘本尺度的宽松 AI 判断。素材目录“第四关”在游戏中排列为第二关。

## 本次改动与原因
实际体验暴露旧提示词的冲突：前文允许补足日常操作，后文却要求木筏移动方式、稳定板面等细节，并把潜在风险当成必然失败。新版按日常中文理解，默认公主乘坐她制作的浮具，补足普通动作，只追问真正无法辨认的主要意图。允许绘本式适度夸张，仍禁止架空能力、图外关键物品、伤人或本关不允许的警报。
两关分别使用可信物体、目标、位置枚举和本关事实 Markdown；没有关键词成功规则或固定答案列表。成功评分不再倒推通关安全门槛，五项只描述本次方案。
生图只编辑无公主背景，程序使用用户两张原始 PNG 合成初始/成功公主；第一关局部去除原人物，第二关使用含梯子的完整背景。角色不会交给模型重新绘制。结果核对基于实际合成图。

## 实际限制
生图与开放方案判断有随机性，少量成功样本不代表全部方案准确；位置检查也可能误读。系统异常保留原句，不能算作孩子失败。对新增组合应分别定位理解、常识、背景编辑或核图环节，不建立关键词成功名单。联网生成可能产生火山方舟账号费用，未作费用保证。
