# AI 儿童创造解谜

这是《公主救王子》第一关的本地 Web 原型。直接双击 `index.html` 可以进入离线演示；演示模式不需要 API 密钥。需要调用 AI 时，在页面的“AI 设置”中填写 OpenAI 兼容接口地址、模型和 API Key。

入口流程：故事书封面 → 关卡选择 → 黑底开场白 → 第一关场景。当前只有第一关的演示交互；第二至第五关仅有选关卡片与开场白，尚无可玩场景。第一关判定为关键词演示，并未实现完整物理规则。语音输入、AI 图片生成与真实 API 联调仍待完成。静态文件和 JavaScript 语法检查已通过，浏览器完整流程尚未完成验收。

## 本地运行

1. 双击 `index.html`，或在项目目录运行 `python -m http.server 4173`。
2. 打开 `http://127.0.0.1:4173/`。
3. 点击场景中的热点阅读事实，输入一句方案，再点击“让 AI 判断”。

项目没有第三方运行时依赖，Python 3.12 仅用于可选的本地静态文件服务器和检查脚本。无需全局安装 Node、npm 或框架。

## AI 模式

页面保存的 API Key 只存在当前浏览器的 localStorage，并直接发送到你填写的接口；项目代码没有内置任何密钥。默认使用 `/v1/chat/completions`，返回内容要求为 JSON。最终成功/失败仍由本地关卡规则判定，模型只负责把自然语言映射到配置中的物体、动作和方法。

如果浏览器阻止 `file://` 页面发出的跨域请求，请用上面的本地静态服务器打开页面。离线演示不受影响。
