# 公主救王子 · 创造解谜故事书

面向 7–10 岁儿童的本地网页游戏。观察绘本里的物体，用一句话尝试让公主安全过河。

本期实现：故事书封面 → 关卡本 → 黑底剧情 → 第一关「过河不拆桥」→ 反馈 → 重玩。后续关卡显示「待开放」。第一关使用 2026-10-11 更新的背景：木桶在左岸、长桥板、伸到河中央的滑轮绳。
统一加载页采用新增城堡与叶子素材。首次打开进度条匀速走满至少 2 秒；关卡木牌下拉后停留 2 秒再收回。物体提示只提供物理特点，不提供解法建议。

## 在 Windows 上启动

1. 下载或克隆本仓库，解压到一个本地文件夹。
2. 双击 **启动游戏.cmd**。第一次会把官方 Node.js 运行环境下载到本仓库的 `.tools` 文件夹，并核对下载文件的 SHA-256；需要联网。
3. 浏览器自动打开 `http://127.0.0.1:4173/`。以后运行环境已存在，双击即可。
4. 关闭网页后服务可以继续运行；需要结束服务时双击 **停止游戏.cmd**。

也可先双击 **准备本地环境.cmd**。没有全局安装、没有第三方 npm 依赖。不要直接打开 index.html，AI 请求需要本地服务转发。

## 配置火山方舟

界面、观察、音乐、剧情可直接体验。密钥为空时提交会显示 **AI 尚未接入**，保留原句，不产生演示通关。

1. 第一次启动后，在项目文件夹内用记事本打开 `.env`（由 `.env.example` 自动复制）。
2. 只在 `ARK_API_KEY=` 后填入自己的火山方舟 Key。不要把 Key 发到聊天或上传仓库。
3. 默认文字模型为 `doubao-seed-2-1-pro-260915`，图片模型为 `doubao-seedream-5-0-flash-260915`。Key 需拥有这两个模型的调用权限和可用额度；实际可用性以账号为准。
4. 双击「停止游戏」，再双击「启动游戏」使配置生效。

密钥由本机服务读取，网页和浏览器存储不持有密钥，`.env` 不提交 Git。游戏本身运行在本机；使用 AI 时会向火山方舟发送玩家句子、追问上下文、关卡背景和必要的本地物体参考。图片是联网生成，可能产生账号费用。

## 判定与评分

按顺序检查表达、关卡限制、物理常识和目标。只用图中物体、用一句话；不检查公斤、厘米等数值，不按固定答案或关键词自动判通关。树叶与岸边土可以使用，但是否可行仍需常识判断。

判断后编辑完成后的画面，再核对结果。生图优先借用同关卡人物、木桶、桥板、绳子、滑轮和石块素材，减少外观变化；成功必须显示公主已经站在右岸。发现画面矛盾会按具体问题重生成一次，仍异常则提示系统错误。这不能保证模型每次都准确。成功才显示五维 0–10 分五边形：物理推理、想象力、观察力、规划力、安全意识。每项解释这一次方案的具体表现，不给孩子排名或能力标签。
